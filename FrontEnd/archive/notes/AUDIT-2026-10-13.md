# RoadNa JO — Project audit (2026-10-13)

**What was checked:**
- An automated scan of all 21 screens plus `shared/`: metadata, IDs, headings, images, form labels, focus styles, copy, broken characters and file sizes.
- The Vercel Web Interface Guidelines.
- A visual check at 1280px, 800px and 375px, and in right-to-left layout.

Nothing was changed in the project. Sizes: **S** is under an hour, **M** is a few hours, **L** is a day or more.

- Every form field has a label, including the search boxes, which use screen-reader text inside a `<label>`.
- Focus is always visible: wherever an outline is removed, a teal ring replaces it.
- Reduced-motion support exists in 32 files.
- `aria-live` and `aria-current` are used consistently.
- No `transition: all`, and no zoom lock in the viewport tag.
- No garbled characters in any file. The "â€”" seen earlier came from the PowerShell display, not the files.

- `npm run check` passes.

## A. Fix now (small, high value)

### A1. The sample content is not Jordanian (M) — the biggest credibility issue
The screens use US-style names, places and units. CityWorld uses Jordanian districts, so the product contradicts itself.

| What | Where |
|---|---|
| "Marcus Vance" (17×) | create-report, home-menu, my-reports, notifications, profile, register, report-details, report-submitted |
| "Elena Kovacs" (5×), "Harbor Heights" (16×), "Eastbrook", "Civic Center Boulevard" | admin-dashboard, admin-dispatch-units, admin-heatmap, admin-incident-triage, profile |
| "Elm" (26×), "Maple", "Oak", "4th & Elm" | most resident and admin screens |
| "Oak & 8th Ave", "Pine St Park", "25 MPH", "Maple Ave" | `screens/landing-page/index.html:220`, `:226`, `:231`, `:232` |
| US phone "+1 (312) 847-1928" and email "@metropol.gov" | `screens/profile/index.html:137`, `:133` |

**Fix:** use one set of Irbid-style names, districts, streets, `+962` phone numbers and km/h. See D1.

### A2. Old years and inconsistent report codes (S)
- "© 2025" appears in 7 places:
  - `login/index.html:59`
  - `register/index.html:90`
  - `reset-password/index.html:88`
  - `forgot-password/index.html:83`
  - `check-email/index.html:74`
  - `password-updated/index.html:61`
  - `landing-page/index.html:293`
- Report codes are `RN-2025-0412` on the screens but `RN-1041` in CityWorld. Pick one format (for example `RN-2026-0412`) and use it everywhere.

### A3. Misleading security badges (S)
- "Municipal Encrypted SSL" (`landing-page/index.html:294`, `password-updated/index.html:62`), "Secure Civic Gateway" (`login/index.html:18`) and "Encrypted Authentication" (`forgot-password/index.html:73`) claim security that a static preview does not provide.
- Replace them with an honest "Preview — nothing you type is sent", or remove them.

### A4. Password placeholders look like a saved password (S)
- `placeholder="••••••••••••"` at `login/index.html:44`, `register/index.html:60` and `:70` looks pre-filled.
- Use "Enter your password" or "At least 8 characters". `reset-password` already does this correctly.

### A5. Missing favicon on 20 of 21 screens and the root `index.html` (S)
Only the landing page has one, so every other tab shows a blank icon.

### A6. Missing skip link on the 12 app screens (S)
- Affected: all `admin-*` screens, create-report, home-menu, my-reports, notifications, profile, report-details and report-submitted.
- The landing and sign-in screens already have one.

### A7. The login page has no meta description (S)

### A8. CityWorld is linked publicly, and admins have no link to it (part of the role work)
- The landing page links to CityWorld 5 times (`landing-page/index.html:47`, `:73`, `:97`, `:142`, `:274`), and the root `index.html:37` links to it too.

## B. Design and UX enhancements

### Residents (phone first — most reports come from someone standing in the street)
1. **Home on a phone (S):** the 4 stat cards are stacked and fill the whole first screen. Use a 2×2 grid and show "Your active reports" first.
2. **Bottom tab bar on phones (M):** Home · Map · **＋ Report** · My reports · Profile, replacing the hamburger menu. Everything is then reachable with one thumb.
3. **Report form (S):**
   - The later step labels ("Location") are very faint.
   - The breadcrumb in the top bar wraps to two lines at about 800px.
4. **Resident 2D map (L):** already planned. Show reports near the resident as pins, with a details sheet for each.

### Admins
5. **Command City entry (M):** add it to the admin sidebar, with the "jump" transition from the dashboard. This is already planned and closes A8.
6. **Heatmap on a phone (S):** the filters fill the whole first screen and push the map below the fold. Collapse them into a "Filters (2)" button that opens a sheet.
7. **Aligned numbers (S):** use `font-variant-numeric: tabular-nums` on all stat cards and tables so figures line up. Only 5 files use it today.
8. **Print styles (M):** add them for work orders and report details. There are none today, and crews and offices still print.

### Landing
9. **Shorter story on phones (S):** the story is 660vh, about 6.6 screens of swiping. Use about 480vh on phones. The "Skip intro" link already exists.
10. **Share previews (S):** add Open Graph tags (title, description, image) so links shared on WhatsApp or Facebook show a preview. Use `assets/city/cityworld-overview.jpg` as the image.

### Arabic (the biggest product upgrade for Irbid) (L)
11. Full Arabic, built on the RTL work that already exists:
    - A locally hosted Arabic font, such as IBM Plex Sans Arabic or Noto Kufi Arabic.
    - All interface text in one dictionary file.
    - `Intl` formatting for dates and numbers.
    - An option for Arabic-Indic numerals.

### Later
12. **Dark mode (M):** CityWorld already has a night look that the rest of the app could borrow.

## C. Performance

1. **Fonts (S):**
   - The fonts are TTF (238 KB in total, `shared/base.css:4-7`).
   - Converting them to WOFF2 roughly halves the size.
   - Add `<link rel="preload">` for the regular weight.
2. **Unused heavy images (S):**
   - `story-road.png` (3.6 MB) and `story-car.png` (1.9 MB) are used only by `screens/landing-page/original.html`, the old backup page.
   - Move that page and the PNGs into `checkpoints/` to remove 5.5 MB from the shipped folder. WebP copies already exist.
3. **Landing icons (S):** 11 icon `<img>` tags have no width and height, which causes a small layout shift. Switch them to the SVG sprite the app screens already use.

## D. Code health and tooling

1. **One sample-data file (M):** each screen hard-codes its own people, places and codes, which is why A1 and A2 drifted. Add a `shared/sample-data.js` (names, districts, reports, crews) that both the screens and CityWorld use.
2. **Stronger `tools/check.mjs` (S):** have it fail on a missing favicon, a missing skip link, more or less than one `<h1>` (outside `inert` areas), duplicate IDs, images without dimensions, stale years, and US sample words. This stops these problems coming back.
3. **Put the project under git (S):** it is not a git repository. The `checkpoints/` folder is manual versioning. `git init` plus a first commit gives safe undo and history at no cost.
