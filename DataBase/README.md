# DataBase

The database design for SQL Server, as a small website: ER diagram, schema diagram, table list, SQL script and the rules the schema guarantees. Every view is drawn from one file, [database-data.js](database-data.js), so they always agree.

Open [database.html](database.html) in a browser (no server needed), or run the front end server and visit http://127.0.0.1:4173/database/.

To change the design, edit `database-data.js` only. `assets/` holds the styles and fonts the page needs, so this folder works on its own.
